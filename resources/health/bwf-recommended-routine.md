# r/bodyweightfitness Recommended Routine (reference)

External reference template from the r/bodyweightfitness community. Not a personal routine — kept as reference material for pair-based bodyweight programming.

## Required Equipment

- Pull-up Bar
- Parallel Bars
- Gymnastics Rings
- Bands

## Warm-up: Dynamic Stretches

1. Shoulder Band Warmup (5-10 reps)
2. Squat Sky Reaches (5-10 reps)
3. Wrist Prep (10+ reps)
4. Deadbugs (30 s)
5. Arch Hangs (10 reps)
6. Support Hold (30 s)
7. Shrimp Squats (10 reps)
8. Nordic Curls Negatives (10 reps)

## Strength Work

1. First Pair
    1. Pull-up Negatives (3 x 5-8 reps)
    2. Shrimp Squats (3 x 5-8 reps)
        1. (Alternative): Pistol Squats (3 x 5-8 reps)
2. Second Pair
    1. Parallel Bar Dips (3 x 5-8 reps)
    2. Nordic Curl Negatives (3 x 5-8 reps)
        1. (Alternative): Single Legged Deadlifts (3 x 5-8 reps)
3. Third Pair
    1. Horizontal Rows (3 x 5-8 reps)
    2. Diamond Push-ups (3 x 5-8 reps)
4. Core Triplet
    1. Ring Ab Rollouts (3 x 8-12 reps)
    2. Banded Pallof Press (3 x 8-12 reps)
    3. Reverse Hyperextensions (3 x 8-12 reps)
        1. (Alternative): Arch Body Holds (3 x 8-12 reps)
