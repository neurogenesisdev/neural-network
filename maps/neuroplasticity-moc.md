# Neuroplasticity MOC

> [!info] Purpose
> This MOC gathers notes about brain plasticity, cognitive enhancement, and the mechanisms that allow the brain to change and adapt.

## Core Concepts
- [[neuroplasticity]] - The brain's ability to reorganize itself
- [[bdnf]] - Brain-Derived Neurotrophic Factor, key growth protein
- [[neurogenesis]] - Formation of new neurons

## Upregulation Methods
These practices increase neuroplasticity:
- [[intermittent-fasting]] - Metabolic stress → BDNF increase
- Exercise - Aerobic activity → neurogenesis
- Meditation - Attention training → structural changes
- Sleep - Memory consolidation, synaptic pruning
- Learning - Novel experiences → new connections
