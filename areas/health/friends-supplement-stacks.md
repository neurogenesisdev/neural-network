# Friends' Supplement Stacks

Reference collection of supplement / nootropic stacks for friends the user is helping. Each friend gets their own `##` section. Append new friends below; keep personal stacks out of this file (those live in [[daily-supplement-stack]]).

> [!NOTE] Purpose
> These stacks are for reference when discussing supplementation with friends — not prescriptions. Dosing recommendations here reflect protocols shared between the user and each named friend; they are not medical advice and should be adjusted against each person's bloodwork, diet, and circumstances.

## Mia

Consolidated from former `Areas/Health/Mia's Stack.md` + `Areas/Health/Mia's Supplement Stack.md`. No data lost — the two source files were near-duplicates (~90% overlap); this section contains the union.

### Morgens (alles zusammen, mit etwas Essen oder einfach mit den Ölen)

- **Vitamin D3 + K2-MK7**
  - Sommer: 5 000 IE D3 + 180–360 µg MK-7
  - Winter: 10 000 IE D3 + 240–360 µg MK-7
- **Hochdosiertes Fischöl (EPA-lastig)** — ca. 1 000–1 300 mg EPA + 600–800 mg DHA (Gesamt 2–4 g Omega-3, EPA > DHA)
- **Kupfer-Bisglycinat** — 1,5–2 mg elementares Kupfer

### Abends (mit oder nach dem Abendessen / vor dem Schlafen)

- **Zink-Bisglycinat oder Zink-Picolinat** — 25 mg elementares Zink
- **Magnesium-Bisglycinat** — 250–300 mg elementares Magnesium

### Optional — nur bei nachgewiesenem Eisenmangel (Ferritin < 70 ng/ml)

Morgens nüchtern (mind. 2 h Abstand zu Kaffee / Tee / Milchprodukten), jeden 2. Tag (oder täglich wenn Ferritin < 30):

- **Eisen-Bisglycinat** — 18–25 mg elementares Eisen
- **Vitamin C** — 500–1 000 mg (für bessere Aufnahme)

Weitermachen bis Ferritin 70–100 ng/ml erreicht ist, dann absetzen oder stark reduzieren.
