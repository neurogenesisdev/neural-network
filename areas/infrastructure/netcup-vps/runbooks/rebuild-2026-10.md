## As actually done 2026-10-18 (the lessons)

- **Stage 2 needed four runs.** (1) `IPV6_GW` line lost in a hand edit → unbound variable. (2) `initramfs-tools` is only *recommended* by the kernel on 26.04; with `--no-install-recommends` there was no `update-initramfs`. (3) My `resolv.conf` symlink into `/run/systemd/resolve/` dangled inside the chroot → apt could not resolve; fix: copy the rescue host's file during the chroot, set the stub symlink at the end. (4) Postcondition grep wanted `GatewayOnLink=yes`; netplan 1.2 writes `true`. Script fixed for all four. Review lesson: two model reviews caught syntax and logic, **not chroot runtime** — a dry run in a throwaway VM would have.
- **Kernel panic on first boot** (`VFS: Unable to mount root fs on /dev/vda3`): `update-grub` ran *before* `update-initramfs -c`, so `grub.cfg` had no `initrd` line and the kernel had no btrfs module. Fix from rescue: mount `@`, bind-mount, `chroot /mnt update-grub`. Script order swapped + a postcondition. Also `root=/dev/vda3` instead of UUID is normal from a chroot (grub-probe), harmless on one virtio disk.
- **Panel firewall rules are top-down, first match.** `temp-rescue-ssh` placed *below* `tailnet-only` never fires (rule 9 `DROP TCP *` wins). And the imported policy had silently not been saved. Ping is not a liveness test here — the policy drops it.
- **`ssh netcup` after the rebuild:** the laptop's `IdentityFile` must point at the `.pub` (the private key lives in the KeePassXC agent); `ControlMaster` reused the old public-IP session and faked "public still reachable" and "group not applied" — `ssh -O exit netcup` or `-o ControlPath=none` before trusting any test.
- **`| tee` suspended apt** (ubuntu-pro-client postinst touched the tty from a background process group → SIGTTOU, state `T`); `kill -CONT` resumed it. Stage 3 header now says `script -q -c`.
- **`grep -q` + `set -o pipefail` = false FAIL** (SIGPIPE to the producer). All postconditions now grep a captured string.
- **`tar -xzf bundle -C /` with a user-built tarball set `/etc` and `/usr` to `0700`** (laptop umask 077 → the archive's directory entries carried `drwx------`, and GNU tar applies archive modes to *existing* directories). Non-root could not traverse `/usr` → `sudo`, `sed`, new logins all dead; fixed from the rescue system with `chmod 755` on the nine directories. **Rule: never extract a bundle onto `/`. Stage into `/tmp`, `install` each file with explicit owner/mode.** Second lesson from the same block: a glob under `sudo` expands in *your* shell (`chmod 600 /etc/credstore/*` found nothing); and `restic-b2*` also matched the two `.d` directories.
- **restic backup paths gained `/srv`** (own subvolume; `--one-file-system` would skip it). First snapshot from the new host: `ed4da8c5`, 3.4 GiB / 1.9 GiB new.
- **sudo-rs** is Ubuntu 26.04's sudo (the refusal text is "I'm sorry dev, I'm afraid I can't do that"); same sudoers, same `-n` semantics.
- **Remote Control** stores a one-time consent per user; run it interactively once before enabling the units. Spawned-session names are auto-generated; only the first (pre-created) session gets `--name`; sessions can be renamed in the app. The Code tab's device → Directory picker chooses where *New session* lands, it does not filter the list.
- **sudo-rs + pipes, the real mechanism** (confirmed against an independent report, voco PR #128): when sudo-rs's stdout is a pipe it runs the command in the *background* of its own pty with input cut; APT reads the terminal once before dpkg starts (`DPkg::FlushSTDIN`) → `SIGTTIN` → stopped; sudo-rs resumes only its direct child. Classic sudo (Debian 13, Ubuntu 24.04) does not. **Rule: no pipe after `sudo` when apt is anywhere in the tree**; unstick with `sudo pkill -CONT apt-get`. Bit us three times (stage 3 `| tee`, playwright `| tail`, and the ssh-remote-command variant).
- **Recommends-only dependencies on 26.04 with `--no-install-recommends`:** `initramfs-tools` (kernel), `aardvark-dns` (podman — container name resolution). Both now explicit in stage 3.
- **`sudo install -d -o dev …/.config/ntfy` creates the parent `.config` as root** — mise then cannot write `~/.config/mise`. Create the parent explicitly with the right owner, or `chown` it after.
- **zsh's `NOMATCH`:** a glob that matches nothing aborts the line; under `sudo ls dir/*` the glob is expanded by *your* shell, which cannot read `dir`, so it "matches nothing". `setopt NO_NOMATCH` in zshrc.local. Comments with `(…)` typed into a shell without `INTERACTIVE_COMMENTS` yet are parsed as glob qualifiers.
- **Ubuntu `chromium` is a snap shim**; Playwright brings its own Chromium. **Codex's bwrap** needs an AppArmor profile granting `userns` (Ubuntu restricts unprivileged user namespaces since 24.04).
- **Rootless podman start blocks for the image pull** — `podman pull` the pinned digest in the foreground first, then `systemctl --user start`.
- **Expiring API keys fail silently** unless the error path notifies; the n8n classifier was red for four days before anyone looked. Every key with an expiry gets a rotate-by date in KeePassXC *and* the backlog.
